# Create issue for dev on github

Create dev first issue in github

## Usage

``` r
add_issue_dev_github(owner, repo)
```

## Arguments

- owner:

  owner of the project

- repo:

  name of the project

## Value

tibble with github issue info

## Examples

``` r
if (FALSE) { # \dontrun{
add_issue_dev_github(
  owner = "owner",
  repo = "repo"
)
} # }
```
