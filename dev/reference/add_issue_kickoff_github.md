# Add Kickoff issue for GitHub

Add Kickoff issue for GitHub

## Usage

``` r
add_issue_kickoff_github(owner, repo)
```

## Arguments

- owner:

  GitHub owner (username or organisation)

- repo:

  Name of the repository

## Value

A tibble with the issue added and GitHub infos

## Examples

``` r
if (FALSE) { # \dontrun{
add_issue_kickoff_github(
  owner = "owner",
  repo = "repo"
)
} # }
```
