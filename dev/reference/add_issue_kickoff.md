# Add Kickoff issue client for GitLab

Add Kickoff issue client for GitLab

## Usage

``` r
add_issue_kickoff(project_id)
```

## Arguments

- project_id:

  project_id

## Value

A tibble with the issue added and GitLab infos

``` r
if (FALSE) { # \dontrun{
```
