# Add First issue client for GitHub

Add First issue client for GitHub

## Usage

``` r
add_issue_clients_github(owner, repo)
```

## Arguments

- owner:

  GitHub owner (username or organisation)

- repo:

  Name of the repository

## Value

A tibble with the issue added and GitLab infos

## Examples

``` r
if (FALSE) { # \dontrun{
add_issue_clients_github(
  owner = "owner",
  repo = "repo"
)
} # }
```
