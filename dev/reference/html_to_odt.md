# Convert html to odt with template

Convert html to odt with template

## Usage

``` r
html_to_odt(input_html = "_main.html", output_odt = "_main.odt")
```

## Arguments

- input_html:

  Path to html file to convert

- output_odt:

  Path to odt to create

## Examples

``` r
if (FALSE) { # \dontrun{
html_to_odt(input_html = "_main.html", output_odt = "_main.odt")
} # }
```
