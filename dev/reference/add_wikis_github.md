# add_wikis_github

add_wikis_github

## Usage

``` r
add_wikis_github(owner, repo, type = c("home", "cr", "keys", "weekly"))
```

## Arguments

- owner:

  Owner of the repository

- repo:

  Repository name

- type:

  Wiki type to add

## Examples

``` r
if (FALSE) { # \dontrun{
add_wikis_github(
  owner = "ghowner",
  repo = "areponame"
)
} # }
```
