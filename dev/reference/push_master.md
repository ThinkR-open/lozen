# Push master to server

Push master to server

## Usage

``` r
push_master(
  project_path,
  branch = "master",
  main_branch = "master",
  message = "Init repo"
)
```

## Arguments

- project_path:

  project_path

- branch:

  branch name. main by default

- main_branch:

  main branch name. main by default

- message:

  commit message
