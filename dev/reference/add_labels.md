# Add labels to project

Add labels to project

## Usage

``` r
add_labels(project_id, lg = "fr")
```

## Arguments

- project_id:

  project_id

- lg:

  by default, fr to get labels in french. Use en for english

## Value

Table of added labels. Side effect: labels added on GitLab.

## Examples

``` r
if (FALSE) { # \dontrun{
add_labels(
  project_id = project_id
)
} # }
```
